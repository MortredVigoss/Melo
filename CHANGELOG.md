# Changelog

A brief overview of user-facing updates. Technical details live in the project documentation and commit history.

## 2026-10-21

- Integrated Android with shared Agent behavior, context, search, and execution records.
- Added topic dividers and navigation to earlier topics on desktop and iPhone.
- Improved iPhone handling of long inputs, conversation context, and synchronized topic labels.
- Fixed ordinary replies being marked as blocked and kept reference material separate from search and completion decisions.
- Refined desktop settings and improved reliability across clients.

## 2026-10-20

- Restored previews of older generated images while preserving the originals.
- Agents can request additional capabilities when needed, with explicit approval and revocable temporary permissions.
- New custom Agents start with read-only capabilities and can use an existing Agent as a starting point.
- Improved desktop and mobile consistency, search routing, memory writes, and file approvals.

## 2026-10-19

- Improved recovery after saving Agents and projects, preventing duplicate changes.
- Fixed project memory edits and made desktop settings easier to maintain.
- Aligned iPhone execution limits, cancellation, failure recovery, and follow-up instructions with desktop behavior.
- Added more focused development checks while retaining full release validation.

## 2026-10-18 — iPhone 0.7.0 (32)

- Added webpage reading and screenshots on iPhone, including supported API-key connections.
- Improved handling of long conversations, attachments, sync conflicts, and interrupted requests.
- Improved date awareness and read-aloud summaries and language selection.
- Strengthened tool permissions, URL checks, and private-data handling in execution records.

## 2026-10-17

- Improved model and tool compatibility, with clearer execution feedback and limits.
- Better handling of long conversations, earlier topics, and large attachments.
- Shared project memory and personal preferences, with controls for what Melo remembers.
- Improved iPhone conversation sync and memory conflict handling.
- Temporarily archived Telegram and Discord integrations, preserving existing settings and history.

When updating, keep your existing data directory. See [Run from source](README.md#run-from-source) for installation steps.
