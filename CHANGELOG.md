# Changelog

A brief overview of user-facing updates. Technical details live in the project documentation and commit history.

## 2026-10-19

- iPhone agent loop now works like the desktop: one loop for Codex sign-in and API-key connections with the same limits (10 model calls, 32 tool calls per response), run budget (20 min / 400k input tokens / 120 tool calls), repeat-failure guard, `{ok,status,code,output,hint}` tool results, condensation of older tool output when a request is too large, supplements that join the next step instead of restarting the reply, a `[工具轨迹]` note after a stopped reply, uncertainty verification for factual answers, and a phone `read_history` for synced desktop summaries; limits and texts are shared with the desktop through `shared/protocol/agent-loop.json`.

## 2026-10-18 — iPhone 0.7.0 (32)

- Global bug audit (`docs/bug-audit-20261018.md`) and fixes across tools, long conversations, memory, iPhone and desktop UI: tool results keep their `empty` status; the screenshot tools re-check redirects and block private hosts on both platforms; background compaction no longer clobbers per-chat runtime fields; secrets inside tool arguments and outputs are redacted in records; stable prompt blocks no longer crowd out memory recall; local models get a window derived from the measured prompt; hand-written memory-book rows survive scope changes; iPhone screenshot size caps, cancellation, request-shape and sync-convergence fixes; UI state and i18n coverage.
- Date continuity: the prompt now says that earlier messages were written at their own time, and when a conversation crosses midnight the turn carries a short note ("the previous message was sent yesterday") — the model no longer "corrects" a previous reply's "今天". iPhone requests now include the current local date (they carried none).
- iPhone auto-read: speaks a condensed version of the reply (conclusions and numbers; no URLs, link targets, code, tables or markdown), and picks the voice by the reply's own language first (Chinese replies in Chinese on an English phone), then the voice-language setting, then the device language. The setting is now labelled "语音语言（听写与朗读）".
- iPhone web pages: the assistant can now open a link (`open_url`, readable text in 12 000-character pages) and screenshot it (`web_screenshot`, attached under the reply and shown to the model) on the phone itself, following the Agent's "联网搜索" phone permission; these and the phone data tools now also work on API-key connections (Chat Completions and Anthropic), not only on Codex sign-in.
- iPhone audit fixes (docs/bug-audit-20261018.md §4, I1–I22): `open_url` page numbers can no longer crash the app; screenshots are captured at 1× and capped at 1 600 × 4 096 px with JPEG encoding off the main thread, at most 2 per reply, earlier ones replaced by their caption on later rounds and byte-budgeted (6 MB) per request; the loader stays renderable off-screen instead of hidden and reports "App 不在前台" when no window exists; waiting for a page now honours cancellation; HTTP error pages are returned with their `status` instead of `LOAD_FAILED`; long titles no longer sink the whole result. The private-address check now parses literal IPv4/IPv6 by bytes (`127.1`, `0x7f000001`, `2130706433`, `0177.0.0.1`, `[::ffff:7f00:1]`, NAT64/6to4 embeddings), strips trailing dots and refuses `.internal/.home.arpa/.lan/.localdomain`; the permissions page says DNS rebinding is not covered, and its rows are now localized in the five interface languages. Web tools also follow the device-wide "实时搜索与天气" switch. Run-record observations from API-key replies are delivered on the main actor. Tool calls truncated by `length`/`max_tokens` are never executed; the echoed assistant message is whitelisted (`role/content/tool_calls/reasoning_content`) for DeepSeek-style providers; a forced web search for weather/news questions survives the phone tools (first round forced, later rounds free); same-turn `image_generation_call` results are not re-sent each round. Synced memories keep the desktop's `section`/`bookStatus` and no longer bump the phone clock on every export (sync converges); compact `at` stamps compare as instants; a compact without summary or cards, or whose boundary is the pending question, sends the full history; the full instructions (summary, date lines, memory) are built before the length pre-check so a stored question can no longer fail every retry. Read-aloud keeps decimals like 3.5% in one sentence and maps `zh-Hans-CN` to an installed `zh-CN`/same-language voice.
- Tool groups: browser tools are available from the first turn whenever `MELO_CDP_ENABLED=1` (as before the stable-tool-set change); image/document groups also activate from earlier attachments in the chat and from wording such as 截图 / 预览 / 放大 / 文档 / 报告.
- Desktop web screenshots: new `web_screenshot` tool renders a public page in the local Google Chrome — through the logged-in Melo Chrome when `MELO_CDP_ENABLED=1`, otherwise a one-shot headless launch of the same binary (no login state) — saves the PNG next to generated images (`generated/screenshot-*.png`, signed URL, attached under the reply) and shows a bounded JPEG of it to the model for the rest of the turn (never persisted in history). Private/local hosts are refused; with no Chrome installed the tool says to use `fetch_url`. Nothing paid or remote is used.
