# Melo for iPhone — 私人测试版 0.1

原生 iPhone 应用，最低 iOS 17。电脑版关机后，手机可以直接调用自己配置的模型服务。两端通过独立同步服务交换文字聊天记录。当前无需购买 AWS；可部署到任何支持 Node.js 与 HTTPS 的主机。

## 当前交付与边界

- 黑金粒子首页、聊天列表、多轮文字聊天、停止/重试、设备本地持久化。
- 模型密钥及同步密钥使用设备本地 Keychain，不参与同步。
- 自定义兼容 Chat Completions 的 HTTPS 接口与模型名。最近 60 条消息作为模型上下文；尚无流式回复、语音、附件或长期记忆。
- 同步在手机回到前台、回复结束、下拉或手动操作时触发。桌面 relay 运行时每 15 秒同步。
- 首版只同步文字聊天。项目文件、任务、设置、长期记忆和删除操作尚未同步。不要用此版本测试跨端删除：桌面删除的聊天可能被另一端重新带回。
- 模型推理仍需要网络和自己的模型服务凭证；“独立使用”指不依赖 Mac 开机，不代表离线模型推理。
- 云端未部署、真实模型未调用、真机未安装。本机没有签名证书、已连接 iPhone 或可用模拟器运行时，不能宣称已完成真机体验验收。

## 构建

在项目根目录运行：

```sh
./ios/scripts/build-unsigned.sh
```

输出 `ios/dist/Melo-unsigned.ipa`。**这是未签名构建产物，不能直接安装。** Xcode 工程为 `ios/Melo.xcodeproj`。

该脚本使用 Xcode target 构建，避免当前机器 scheme destination 报缺失 iOS 平台组件的问题。签名归档前如出现平台错误，先在 Xcode Settings → Components 完成 iOS 平台安装。

## 账号就绪后导出个人测试安装包

1. 在 Xcode → Settings → Accounts 登录已经加入付费 Apple Developer Program 的账号。
2. 连接并信任 iPhone，按 Xcode 提示启用开发者模式，登记设备。
3. 打开工程，选择自己的 Team；必要时为此账号设置唯一 Bundle Identifier。
4. 可以直接用 Xcode Run 安装，或导出登记设备可安装的 Ad Hoc / Release Testing IPA：

```sh
MELO_APPLE_TEAM_ID='你的团队标识' MELO_BUNDLE_ID='com.yourname.melo' ./ios/scripts/export-signed.sh
```

输出在 `ios/dist/signed/`。付费签名不使用免费账号七天周期，但仍有证书和描述文件有效期，不是永久免签。脚本尚未执行真实签名，因为账号与证书尚未提供。不要把 Apple 密码或证书私钥提交进仓库。

## 手机配置

设置 → 模型服务：填写完整 HTTPS 聊天接口地址、模型名称、自己的 API 密钥。该版支持非流式 Chat Completions 文本响应，不兼容任意厂商的原生协议或网页登录授权。

设置 → 聊天记录同步：填写完整 HTTPS `/v1/sync` 地址和同步密钥。未配置同步时本地聊天正常保存。

## 同步服务部署与桌面接入

同步服务器为单用户私人服务，使用一个随机至少 32 字符的共享密钥。密钥相当于整个同步库的访问权限。经 HTTPS 传输；磁盘文件为明文，未实现端到端加密。

服务机通过环境变量提供 `MELO_SYNC_TOKEN`、`MELO_SYNC_DIR`（持久数据目录）和可选 `PORT`，然后运行：

```sh
node mobile-sync/server.js
```

默认仅监听本机 `127.0.0.1:43129`。将 HTTPS 反向代理的 `/v1/sync` 转发到该端口。不要直接把普通 HTTP 暴露到公网。部署时设置请求大小上限 8 MB、连接限流、持久卷和备份；每个数据目录只运行一个服务进程。

桌面版需要重启到包含本次新增同步接口的源码，并在启动时提供相同的 `MELO_SYNC_TOKEN`。然后在同一环境设置 `MELO_SYNC_URL` 为完整 HTTPS 同步地址并运行：

```sh
node mobile-sync/desktop-relay.js
```

`--once` 只同步一次。桌面默认本地服务端口为 43127，可通过 `MELO_DESKTOP_PORT` 修改。Relay 通过正在运行的桌面服务的原有事务队列写入，避免直接修改电脑上的存储文件。默认不启用同步；没有密钥时新增桌面接口拒绝访问。聊天来自 Telegram/Discord 等外部渠道的记录不导出。

当前总同步快照上限 8 MiB（含正文、工作区与删除记录）；不再按聊天数、消息数或单条正文长度重复限制。超容量明确返回 413，身份冲突仍停止合并，不静默截断。消息按稳定 ID 合并，删除标记优先于旧副本；桌面、同步服务和手机需一并升级。

### Agent 能力同步（2026-10-15）
新版客户端在原有 `/v1/sync` 完成后调用同一私有服务的 `/v1/agent-settings`。沿用同一 Bearer 密钥与 8 MiB 限制，数据保存在独立 `agent-settings.json`；必须同时更新 `server.js`、`agentSettingsProtocol.js`、生成 schema 及协议依赖。旧服务返回 404 时，聊天同步成功，能力设置保留为待同步，不丢弃本机版本。冲突在桌面/手机设置中选择版本。
手机显示能力和团队交接记录，可编辑人设；电脑工具及团队执行仍在电脑。Agent 权限白名单会同步，具体文件/命令授权和账号凭据不会同步。
