# 2026-10-16 图片交互修正

本轮为代码修正与开发验证；没有覆盖实体 iPhone，也没有重启/安装桌面应用。实体手机仍是上一轮 0.5.19 (25)。

## 问题与修正

- 手机输入区移除“生图”按钮、图片模式及处理方式选择。保留照片/文件、图片库、参考图用途与连接/尺寸/质量选项；“继续修改”和旧草稿也回到自然语言分流，不保留隐藏的强制模式。
- 桌面图片选项不再要求选分析/生成/编辑。打开选项不会让普通聊天变成图片任务；数量留空仍按用户要求解析。设置中的“生图”简称改成完整文字。
- 只读设备记录确认：第一次对比度与粉蓝色调整被存成 `analyze`，返回文字建议；下一轮才以 `edit` 返回图片。补充调色、曝光、对比度以及自然做图说法，双端共用同一组 23 条语义样例验证；禁止、引用、教程和代码请求不触发生成，没有原图的调色请求不擅自生成新图。
- iPhone 图片预览使用 `UIScrollView` 的原生缩放：比例持续累积、手指中心缩放、平移与减速、1–4 倍边界弹性、双击放大/复位。更新保存状态不会重置缩放，换图才复位。移除预览表面的 SwiftUI 长按菜单：实测它会抢走平移；聊天图片的长按入口保留，预览内的保存/分享/修改仍有工具栏入口。
- 桌面预览采用图片局部 transform，支持触控板/滚轮、双指指针缩放、拖动、双击及键盘操作。最大 400%，继续拉伸有小幅阻尼超出，松手回到边界；下一次缩放从当前比例继续。
- 桌面对话最大阅读宽度 860→980px，内容区缩小边距；原神经空间布局、输入框行数和字号保留。
