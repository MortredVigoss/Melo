# Melo 桌面界面材质与排版

2026-10-08。延续黑金深空与真实事件驱动的神经网络，不改变执行状态或来源语义。

## 空间规则（2026-10-08 视频参考）

保留黑金深空，将参考中的柔和浮雕、统一光源与功能展开层级转为桌面空间规则：

- 总览按窗口和输入区实测高度共同分配空间：中枢、轨道与五个入口随可用区域一起变大，保留边缘与输入区间隔；大屏不再受旧固定小尺寸限制。中枢最大、入口次之，顶部标签放在侧面。
- 进入功能后，中枢和一级模块缩小退后，同一列分支向左移动，为详情腾出宽度。详情、模块与总览共用一个持久 DOM 工作面；布局只在切换时测量，使用 transform 进行约 760ms 的移动和缩放。
- 中途反向切换从当时可见的矩形继续，后台数据刷新不重启动画；静态模式或减少动态效果时直接呈现终点。连线路径在移动期间更新，停稳后复用采样。
- 中枢各区常亮但克制，悬停/选择提升对应区和路径的亮度。内部微光、前后深度亮度衰减与细小信号共同塑造体积。这里的导航反馈不表示工具执行，执行面板仍只由真实事件驱动。
- 材质共用左上暖色高光、右下冷暗遮挡。工作面、卡片、浮层与对话框使用不同厚度；弹窗保留背景轮廓，背后的界面文字退暗，局部模糊仍限制为 4px。
- 用户进一步明确去除五个图标的圆壳和可见圆圈边界：使用共享神经拓扑生成 240 个粒子、45 条连接的小型立体结构；保留原 DOM 点击面积与键盘入口，GPU 和 Canvas 回退共用拓扑。悬停缩放通过实际按钮测量同步，不改变点击语义。
- 不增加贴图或网络资产；GPU 场景新增一层局部核心微光与三次批量模块绘制。空闲持续 30fps，切换时目标 60fps，隐藏时停止；保留分辨率上限、性能降档和 Canvas 回退。

## 统一规则

`desktop-ui/neuralGlass.css` 最后载入，集中定义表面、边缘、阴影、文字、圆角和间距；组件文件保留布局及状态逻辑。

- 工作区：轻透深色材质，不做整面模糊，保留背景星光。
- 内容卡片：相同暖金细边与深色渐变；引用、选中和执行状态使用原有语义标记。
- 浮层：较厚的同色玻璃、略亮边缘及独立阴影。仅局部 4px 模糊；不对整个动画背景加滤镜。
- 全局弹窗：背景界面文字退暗，深空继续可见。权限说明保留较实的底色与警示色。
- 圆角以控件 10px、卡片 16px、主框架和对话框 22px 分级。常规按钮 36px、输入工具 40px；紧凑窗口单独收缩。
- 主要间距 8 / 12 / 16 / 20px。分支采用统一行高；标题、摘要和辅助文字分级。

覆盖主框架、导航、输入区、模型选择、快捷命令、角色与附件菜单、语音设置、引用抽屉、权限弹窗、执行记录、来源卡片与主线新增能力状态卡片。

## 响应式阅读

桌面宽度小于 1100px 时使用紧凑导航坐标，为工作区留出宽度。聊天网格显式限制列宽，避免长标题撑破面板。

任务空间外加独立阅读视口；较多来源保留其三维位置与可读字号，通过内部滚动查看，缩放控件固定在可见底部。普通滚轮在溢出的来源卡片上用于阅读；在神经空间空白处继续缩放，触摸板 pinch 仍控制缩放。缩回整体视角时释放来源列表高度，再次靠近时恢复，避免视口裁掉未聚焦模块。窗口宽度改变时重新计算来源布局高度，ResizeObserver 只在尺寸值不同的时候更新样式。

## 分段空间光路与脑区深度（2026-10-08）

保留五种区域颜色，覆盖上一版固定浅角度转动：图标主干改成有物理间隙的短光路。五个图标的短线均散布在不同深度，使用透视校正，在正面角度拼回完整符号；知识按用户后续修正改为正四面体（四个等边三角形面），系统为含中央突触的立方核心。两种立体造型同样先投影为识别视图，再将光路拆到不同深度，避免只是在完整模型表面画虚线。

空闲时绕三轴持续慢转。鼠标悬停、键盘聚焦或进入模块后，以 200ms 的短过渡转到识别角度；中途换目标从当前姿态继续，离开后不跳回预设相位。静态与减少动效模式直接到识别角度。

中枢五区各自沿 Z 轴微幅浮动。悬停一级模块、子分支或中枢区域时，对应脑区向相机靠近，目标透视倍率约 1.10。粒子、组织、神经线、传输亮点与分支线端点同步移动。中枢拾取使用每帧投影的区域，直接点击仍走已有模块入口，不产生模型执行。

319 项 UI 回归及语法构建通过，包含姿态中断、快速对齐、透视倍率、投影拾取、Canvas 回退及静态状态覆盖。继续使用 18 次批量绘制和 0 贴图，不增加后处理或网络资源；真实桌面窗口核对了中枢点击。证据位于 `.tmp/neural-depth/`。
