# 项目生命周期实施约定（GitHub #11）

当前处于实现与跨端验证阶段；不能据此关闭 issue。沿用现有提交回执与 v1 同步，不删除聊天、原图或用户外部工作目录。

| 操作 | 可观察行为 |
| --- | --- |
| 归档 / 取消归档 | 沿用已有归档字段，保留归属和数据；归档项目不能创建新对话 |
| 移动聊天 / 解除归属 | 只改变未来回合的项目；不重写已完成运行和 commandRuns 的目标快照；拒绝运行中切换；旧待审批改为失效，需要重新请求 |
| 删除 | 保留已删除项目记录与操作 ID；聊天解除归属，知识与资产保留；项目记忆保留在旧命名空间且不自动变为全局；拒绝有运行中回复、命令、审批的项目删除 |
| 恢复 | 从保留记录创建新的项目 ID，旧 ID 的删除记录永久保留；不自动移动聊天、执行旧审批或扩大 Agent 权限；目录只恢复关联，不递归写入或删除内容 |

同步使用既有 knowledge 记录承载有版本的删除信封，避免向冻结 v1 项目字段添加旧端不认识的属性。信封不包含本机路径、凭证或能力配置，默认不在知识列表显示。删除采用 remove-wins：合并全部版本时识别有效 tombstone，清理该 ID 的项目记录与未来归属；离线旧写入不能移除 tombstone。旧客户端可能仍显示离线缓存，重新连接后不能把旧项目带回新版状态。恢复生成新 ID，避免把时间戳比较当删除授权。

操作日志与删除标记在同一状态事务提交；后续投影或同步失败必须可由相同 operationId 继续，不能重复创建恢复项目。无需清理外部文件，因此恢复不依赖递归文件操作。检查页/回执列明保留聊天、资料、图片引用、旧记忆命名空间与失效审批的数量及 ID。

验收需要真实隔离状态与 HTTP 回归：删除中断后重开、重复请求、旧设备合并、恢复新身份、审批零执行、运行快照不变、外部目录/原图字节不变。同步与手机 UI 入口的实际接线也须验证。设计文档本身不构成实现证据。
