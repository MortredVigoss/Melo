## 修正与取舍

- 同步只自动收紧能力、协作范围/预算和上下文来源；放宽申请保存在本机待确认记录，绑定请求版本及当前配置。冲突选择不代表授权，过期确认拒绝。桌面确认入口要求本机同源浏览器且拒绝同步令牌；可接受或拒绝，编辑草稿期间不能误触确认。
- 项目能力与协作受全局上限约束。旧版人设同步省略项目覆盖时仍保留安全设置，不能借删除人设配置解除限制。
- 无状态文件的全新安装本来已采用推荐能力；补齐空 `{}` 清单路径。已有旧记录仍走迁移预览，远端不能替用户完成迁移。
- 团队先检查全部成员和主 Agent，未迁移时在任何模型调用前明确提示。单次委派同样拒绝未迁移成员，模型工具列表只显示 delegate，agent 别名仍可兼容调用。
- 移除成员单次回复 4096 限制，按剩余累计预算、配置的输出上限和上下文容量限制；回执用量替代固定估算，缺少回执才按实际回复估算。
- 知识切段/清理在资料提交后的派生索引流程执行，文档向量在后台按批更新。检索打开只读数据库，未建或过期索引用当前选用原文回退，避免旧内容；查询向量最多等待 75 ms（硬上限 100 ms），不在首 token 前计算文档向量。
- JS / Swift 人设适配器识别反引号和波浪号围栏，围栏中的二级标题保留为正文；剩余“角色默认”改为“Agent 默认”。
- 复核循环以最后成功且获批准的一轮判断完成，历史失败回执保留；取消仍判失败。
- 内置人设首次保存成为用户配置符合已批准的“默认值只用于第一次运行、状态唯一真相”，继续保留。新增回归确保软件默认模板变化不会静默改写已保存人设。
