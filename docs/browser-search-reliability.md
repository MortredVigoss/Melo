## 发现与修复

- **网址被正文污染**：附件自动提取把 Markdown 结束括号和“查看”拼进查询参数。修正未配对括号的 URL 截断；保留合法的成对括号、IPv6 与编码参数。旧消息在显示时依据原始 Markdown 修复链接，不改写历史回复。
- **缺少复制入口**：正文链接与附件卡片均增加“复制链接”；复制先于整卡打开处理，失败时有反馈。WKWebView 拒绝 Clipboard API 时使用原生编辑复制路径。已在真实 Melo 窗口点击并粘贴核对，结果不含 `)查看`，临时输入已清空。
- **Chrome 异常实例**：发现运行约一天、父进程已退出、使用临时 Playwright profile 的无窗口 Chrome。仅结束该孤立实例后，正常 Chrome 的桌面界面恢复可访问，日常标签保留。Melo 原生打开链接增加系统调用错误回传；网页端能识别弹窗创建失败。
- **追问丢失查询意图**：“1个人”“没行李”“2026年 肯定默认是今年”被当成新请求，未继承待完成的航班搜索。现在只对有限的条件补充向前追溯，遇到新任务或禁止联网立即停止；不把旧搜索授权无限延长。
- **未启用的工具被列为可用**：桌面后端未设置浏览器控制开关，却向模型展示 `browser_open`。现在按请求绑定的能力状态过滤；公开查询仍使用原生联网搜索。不自动启用对浏览器登录态的访问。历史失败记录未保存错误详情，因此不能从那条记录唯一证明旧失败代码；当前配置能复现能力关闭条件。
- **错误解释不准确**：浏览器能力关闭与用户拒绝权限分开记录。搜索规则要求浏览器不可用时继续使用已有公开搜索能力，并区分日期时刻表、参考起价与实时可售报价。
- **日期重复追问**：提示加入本地当前日期；即将到来的月日默认当年并说明假设，已过期或冲突时才澄清。
- **验收发现的启动卡顿**：SQLite 采样定位到整表删除 vec0 向量。快照改为只处理新增、变更和移除的向量，并与文本写入处于同一事务。真实数据库副本 1,209 条记录的同步耗时约 646 ms；增加失败回滚验证。原始数据库已做一致性备份。启动错误页的“重试”现在真正重试服务连接。

## 应有的能力与后续边界

1. **公开航班信息**：联网搜索、读取来源正文、匹配生效日期/星期/机场/时区即可给出有来源的计划班次；当前链路已能做到，不能因为拿不到票价就不查班次。
2. **网页上的当日报价**：需要能读取动态搜索结果、等待加载、核对筛选条件与币种的浏览器能力；本次桌面浏览器确实读到了班次和金额，不能笼统说网站没有数据。若有验证码或登录阻断，应准确提示并换用允许的公开来源。
3. **稳定的结构化实时报价**：可接航空公司或航旅供应商生产 API，按出行日期、人数、舱等、行李条件搜索，再核价。需先确认澳洲航司覆盖、生产访问资格及费用。没有新开付费服务，也没有把 sandbox 数据当真实票价。
4. **输出证据契约**：保留检索时间、日期覆盖范围、每段机场/航班号/当地起降时间、金额币种/人数口径、行李和费用边界、来源链接，以及“计划时刻／搜索报价／已核价”的状态。

供应商资料：[Amadeus API FAQ](https://admin.developers.amadeus.com/self-service/apis-docs/guides/developer-guides/faq/) 区分 Flight Offers Search 与 Flight Offers Price（最新价格和可售性确认）；[Duffel Offers](https://duffel.com/docs/api/v2/offers) 描述可购买航班报价；[Duffel test mode](https://duffel.com/docs/api/overview/test-mode/duffel-airways) 明确测试时刻与价格不保证真实。
