|---|---|---|

| 模型连接向导 | 供应商卡片区分 API Key、支持的直接授权与本地模型；小请求实际探测；分别显示请求模型、返回模型及授权、额度、模型名、限流、超时问题 | 系统 → 模型。协议测试与真实供应商验证分开；没有凭证的供应商不标成可用。沿用当前项目模型连接工作，不使用外部代理代替 Melo 执行链 |
| 任务执行、验收与恢复 | 按真实工具记录生成文件、命令、来源验收清单；工具失败阻止完成；检查后才标记完成；备份恢复前展示当前/恢复内容，并复核文件未变化 | 系统 → 工具与任务。恢复前再次备份当前文件。已记录成功的同任务同参数副作用操作复用回执；中断且效果不明的操作要先检查，再明确允许重试 |
| 权限管理 | Allow once / Deny / Always allow；新增授权按角色、项目和真实工作目录绑定；可筛选、撤销并查看本次允许的依据；固定 npm 命令可以限定授权 | 系统 → 安全。命令限 npm test 或 npm run test/build/lint/check，绑定目录身份与 package.json；目录移动或清单改变后重新询问。已有旧范围规则保留，敏感读写及移动/删除仍逐次确认 |
| 跨端任务接力 | 桌面同步任务状态、检查点、版本与待确认动作摘要；手机查看并提交接力请求；桌面显示请求，由执行设备继续；同版本冲突明确报错 | 手机 → 项目/任务接力，以及已配置的同步端点。授权、密钥及本机执行能力不随检查点同步；接力请求不会自动执行。此版不含附件跨端传输或远程代点权限 |
| 多角色协作、成本与质量记录 | 调查/执行/复核职责预览；调查和复核只能读取与检索，最多两个并行；含执行角色时串行；逐角色结果、失败、取消、用量与估算费用；最近 20 次运行及人工质量评分 | 任务卡 → 多角色协作。继承父角色允许的工具范围；费用按每次请求的模型和填写单价计算，缺用量或单价显示未知。评分由用户核对后填写，不是模型自评 |

普通任务与协作任务都保留用量和费用快照；修改单价不会重算旧记录。订阅登录的用量不自动换算成 API 账单。模型返回的缓存字段按各供应商语义归一化，依据 [OpenAI prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching) 和 [Anthropic prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)。

任务去重覆盖已识别并记录的副作用工具调用，依据任务、工具、工作目录及精确参数匹配；不是对任意外部系统的“恰好执行一次”保证。参数改变、模型更换策略或用户确认重试，仍需检查实际效果。权限范围是应用执行策略，不是操作系统沙箱。

跨端同步需要可达并经过令牌认证的同步服务。Mac 关机后的手机独立聊天依赖手机自身的模型连接；任务在 Mac 上执行仍需 Mac 在线。此次没有部署公共同步服务，也没有将本地协议测试当作真机联调成功。

| 权限体验 | 6/10 | 统一 Allow once / Deny / Always allow；修复工具 Always allow 仅保存当前会话的错误；保存失败保持弹窗；防重复提交并缓存已确认决定；权限页统一撤销工具与文件规则 | 普通工具授权可跨对话和重启保存；文件授权仅限当前真实路径与操作；撤销后重新询问；不同数据目录不互相继承授权 |
| 查找准确性 | 功能项 19/25 | 文件结果先按相关性排序再截断 | 在大量模糊候选中仍能找到准确文件名 |

任务完成的定义是“执行结果可供验收”，并不是模型自称完成。文本任务可以只有回复；涉及文件、命令或外部服务的任务应检查对话中的真实工具记录与结果。重复提交同一请求不会重新执行；恢复按钮是用户明确发起的一次新执行，不是自动回滚，也不保证外部操作具备幂等性。

Always allow 不会绕过操作级检查：普通工具规则适用于当前 Melo 数据目录的后续对话；文件规则绑定真实路径和操作。敏感读取、批量读取、移动、删除及需审批的命令仍逐次确认，对应第三个按钮禁用并说明原因。删除的文件名确认保留。这里的权限层不是操作系统沙箱。
