# #4 历史图片预览修复与实点回执

已修复两处原因：历史图片恢复错误套用当前工作区；任务回看把附件替换为成果 ID 和新签名 URL，原解析入口无法识别。修复提交 `e4e378a` / `a115577`，最终产品验证点为 `a115577`。

## 实现与数据边界

- `src/services/media/savedImages.js`：从同一 home / chat / run 的本地成果记录核对持久消息附件，恢复图片原来的生成位置，并兼容回看展示引用。不会解码客户端 `p` 后授予任意路径访问。
- `src/media/imageRecords.js`：按图片固定已核对的读取目录，修复既有错误登记；与归档共用串行合并，避免并发恢复丢图或覆盖已恢复目录。绑定后目录被换成软链接仍拒绝。
- 只修改本地图片读取登记；原图不移动、不压缩、不重新生成，历史消息和账号不改写。手机独立图片存储、模型通道和文件工具权限不变。

用户已授权修复、回归、实际点击、文档及发布关闭。方案自评 A：范围限资源读取与派生登记；先核对来源再绑定，不放宽路径/跨 home/软链接检查。原安装备份仍在，本轮另留登记副本和原图/消息/配置散列。
