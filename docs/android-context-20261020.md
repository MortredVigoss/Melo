# Android 上下文对齐（GitHub #7）

先逐字节复制主线预算与 token 估算，随后独立提交接入便携 Core。原文与压缩边界由 Android 本机存储持有；Core 负责预算、整轮裁剪和有出处的摘录卡，Host 负责按当前聊天身份回读原文，禁止跨聊天参数越权。图片使用固定保守 token 成本，正文与工具返回共同进入每轮预算。输入或完整工具链超限明确报错，不静默截断当前请求。

项目、资料、记忆来源开关由 Host 捕获并统一过滤后再交给聊天与手机执行器；不更改冻结的 v1 同步协议。压缩卡仅从本对话原文生成，保存消息范围和摘要类型；卡片不覆盖原文，重启保持边界。当前读取工具只读本对话，连续回读必须推进消息 ID 或字符位置。

验收：多语言/图片/工具预算、早期约束回读、整轮与工具链保留、原文分页推进、跨聊天拒绝、来源关闭与执行器传参、保存重启、三协议 localhost 请求和 Android Emulator。无真实账号或实体 Fold 验收。
