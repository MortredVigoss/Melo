# 合成容量基线（GitHub #13）

可重跑入口：`npm run bench:capacity -- --out /tmp/melo-capacity.json`。默认 20 / 200 / 1,000 个聊天，每个 50 条消息、512 字符合成正文，非当前聊天含图片引用；没有图片二进制、真实用户数据、网络或付费模型调用。原始样本见 [基线 JSON](../bench/capacity/baseline-20261020.json)。

## 方法与边界

Apple M5 / Darwin 25.6.0 / Node 22.22.2，产品基准 `4d8e871`，本次新增 harness。每个规模 10 个独立进程冷样本、同一进程预热后 20 次热样本、20 次真实聊天执行入口到 stub 模型边界的本地准备样本。冷进程会清空应用缓存，不清系统文件缓存。p50/p95 使用 nearest-rank；10 次冷样本的 p95 即最大值，不能当高精度总体估计。

显式 `--index deferred` 把派生索引工作排除出本地读取/投影计时，记录并断言 source revision 已送达 dispatcher。它不执行后台索引，因此不代表并发索引或向量库容量；`--index inline` 可另测独立同步索引。首次试跑因意外走同步索引而在 50,000 条 fixture 准备阶段超过五分钟，未计为冷加载结果。macOS 临时目录在注册 dispatcher 前创建，防止 realpath 键变化丢失派发。

## 实测

| 消息 / 聊天 | 冷 Bootstrap p50 / p95 ms | 热 Bootstrap p50 / p95 ms | 本地发送准备 p50 / p95 ms | 完整 JSON 字节 | 稳定 delta 字节 |
| --- | --- | --- | --- | --- | --- |
| 1,000 / 20 | 60.63 / 63.93 | 2.36 / 3.55 | 3.67 / 8.18 | 291,915 | 16,647 |
| 10,000 / 200 | 397.69 / 402.79 | 7.56 / 8.73 | 6.22 / 10.98 | 1,127,426 | 16,647 |
| 50,000 / 1,000 | 1,774.35 / 1,790.25 | 28.90 / 33.85 | 17.04 / 23.70 | 4,841,837 | 16,647 |

50,000 条时，冷进程线程 hydrate 的 p50 为 1,575 ms，占冷 Bootstrap 约 89%；热进程整状态复制约 12 ms，当前聊天复制约 0.12 ms。完整 JSON 序列化冷 p50 9.65 ms、transport 编码 25.49 ms。稳定 delta 是 20 次中除首次完整响应后的结果；原始首次响应保留在样本中。

冷子进程峰值 RSS p95：157 / 203 / 407 MiB；热子进程峰值 RSS：190 / 322 / 845 MiB。RSS 是 OS 报告的整个子进程高水位，包括模块加载、后续搜索与历史切换校验，不是稳定 Bootstrap 活对象大小，也不是手机内存测试。磁盘线程正文分别为 1.73 / 17.34 / 86.78 MB。网络和真实模型 TTFT 未测；stub 到达时间不得当首 token 时间。

## 分页决策

优先边界是冷启动的线程正文按需读取：列表保留目录/摘要，当前聊天单独 hydrate；搜索从可导航的索引定位线程，再读原文。若随后实施，必须先定义历史查询分页协议，保留稳定消息 ID、当前聊天、前端草稿和历史跳转语义。当前聊天仅 50 条，此基线不能证明单个超长聊天不需要分页。

现有热缓存与 delta 对重复读取有收益，本项先保留其行为，并提交可重跑测量，不根据合成数据直接改正文存储或清空历史。下一步容量优化应单独立项并以前后相同 fixture 比较；不把新分页方案列为已经实现。

## 验证

CLI 集成回归使用真实隔离状态、冷子进程、bootstrap、transport 与 UI decoder，检查当前聊天、完整原文、搜索的会话入口、历史选择和增量还原；所有 home 运行结束后清理。草稿属于前端本地状态，不纳入 backend fixture 的测量声明，现有草稿/历史导航回归由完整日常检查覆盖。生成器/统计/CLI 三项通过；完整日常结果见总览回执。未安装应用、未验证 native 渲染、实体设备、后台索引竞争或真实供应商速度。

最终本地集成：`npm test -- --base 4d8e871` 完整日常通过（147.2 秒），全部 JS 与 35 Swift 组通过；含新增 CLI 子进程回归、原草稿/历史语义回归。没有运行安装型发布 gate。

完整日常的 JS 初次为 4,337 通过 / 1 跳过（内置推理资产缺失）；补齐固定 revision 和 checksum 资产后，BuiltinEmbedProvider 三项含真实中文语义推理 3/3、零跳过。未删除或弱化该用例。
