# 双端整合（2026-10-16，Claude）

用户在架构复审后要求“都改，把两端整合起来”。分支 `claude/cross-platform-unify-20261016`，基于 `fd258b4`。

## 设计决定：能力按执行设备生效

- 电脑上的 Agent 能力范围约束电脑上的执行（文件、命令、联网、生成媒体、委派、MCP、技能、连接器）。
- 手机上的执行由手机端按 Agent 设置：联网搜索、生成与修改图片，以及日历、提醒、通讯录、位置。只存在本机、不同步，与系统权限、文件书签同类。
- 手机数据要同时满足三项：设置里打开对应类型、iOS 已授权、当前 Agent 在这台手机上已授权。
- 不改同步协议：线上的能力格式对旧客户端是严格校验的，多一个字段旧版手机和同步服务就会整包拒收。
- 迁移：此前设备级已开启的手机数据只转给默认 Agent「Melo」；其他 Agent 需要单独开启。联网和图片保持原有行为（没有记录的 Agent 默认开启）。
