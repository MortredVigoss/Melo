# 实时通话与桌面 UI 双端覆盖安装

## 发布内容

桌面布局与菜单修复（`54c96302`）和 Mac、iPhone 通话播放修复（`5ce380e3`）在 `6d775b08` 合入 master，已推送 GitHub。iPhone 从 0.7.20（52）升至 0.7.21（53）。本次版本改动只涉及 Xcode 工程内 Debug 和 Release 的版本号与构建号。

## iPhone

原设备上直接安装签名 Release 包，保留原应用标识、签名团队与钥匙串访问组。安装前独立读取三次应用数据容器。三份各有 672 个文件，按相对路径、大小和 SHA-256 核对一致。安装后，系统应用列表确认版本与构建号。首启前再读容器，只有两张启动快照改名，内容哈希一致。

首启成功，随后再次检查同一进程仍在运行。应用记录了 launch 和 active。第五次读取数据容器，19 段聊天、217 条消息、6 个 Agent、27 张原图、连接选择与偏好均保留。草稿与执行记录经 JSON 结构对比相等。80 条容量的运行日志追加本次两个事件并淘汰最旧两个，其余差异来自系统缓存。原图、聊天文件、账户与连接偏好与备份逐字节一致。

## Mac

安装前，真实数据目录与完整备份 7,549 项逐文件核对一致。另保留上一版应用、用户偏好和独立存放的 20 张生成图片。备份含 33 段聊天、752 条消息、6 个 Agent、1 个项目及 26 条资料记录。

11 月 19 日 00 时，完整发布检查 17/17 通过（含 5,219 项 JS、Swift、Android、浏览器与两个原生启动入口），安装脚本原位替换用户应用。正式应用通过签名校验，可执行文件与本次构建一致，桌面快捷方式指向同一份安装。普通启动前再读真实目录，7,549 项与原备份完全相同。

普通启动后，原生窗口回报聊天输入框、可见的输入操作和 5 个导航入口。本机服务实际返回备份里的全部 33 个聊天 ID，3 个已存模型连接可见，当前连接有凭据。33 个对话文件、全部消息、Agent、项目、资料、账号配置与 20 张生成图均核对一致。首启只新增运行记录和锁文件，并更新了派生索引、SQLite 共享内存。

## 验证范围

组合版本已通过集成档 `run-Ectx92`。iPhone 工程版本变更的快速档 `run-UKMUlL` 通过。首轮发布测试记录了一次受控轨迹不完整，首轮集成档的界面语言测试记录了一次 SQLite 锁。两个完整测试任务有重叠。随后单独顺序运行这两项，两项均通过。重新执行发布与集成时，将两套完整测试分开运行，保留原有断言和超时。 最终发布档 17/17 通过。以 `6d775b08` 为基准的集成档 `run-gq2t2o` 通过 5,213/5,213 项 JS、41 组 Swift 和设置浏览器验收。该次集成档无失败、跳过、取消或自动复测。

实体声学通话（真人开口、扬声器播放及打断）需单独实测。设备标识、账户内容和完整数据备份仅存于本机。
