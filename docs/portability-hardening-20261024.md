用户已授权按 A–G 清单实施。基准 `5afb0be`；保留现有账号、聊天、原图与其他线程 WIP。本轮不重复 agent loop / memory 架构改造，不运行 git pp，不自动推送或安装。

## 执行顺序

1. C：自定义声音状态按明确服务类型和配置地址识别，健康检查跟随地址；集中本机服务默认地址，保留用户覆盖。
2. A：模型能力由连接自己的目录元数据、验证回执和用户覆盖组成；未知能力显式提示，不能按模型名丢掉图片。推理参数按声明的能力和值传递；集中默认模型，保持旧账号保存值。
3. B/F/G：统一回复语言解析与共享文案表，Agent 指定 → 本次用户语言 → 频道/界面回退；事件使用可翻译消息标识与参数，旧事件可读。覆盖五种界面语言及时间/默认语言回退。
4. D：任务 owner 由现有 Agent 校验，规范化时不抹掉自定义 ID；团队预设只描述职责标签，实际成员由用户明确选择，别名来自 Agent/频道配置。
5. E/F：登记数字和语言规则清单；用户可感知的搜索数量/超时进入设置；已归档渠道的回复阈值保留为运维配置，运维项进入带边界校验的配置；纯实现/安全上限不无差别开放。

## 验证不变量

- 模型别名、任意模型 ID、切换连接、显式关闭视觉与推理能力均可验证；不会把另一连接同名模型的能力带过来。
- 文字、图片原件和失败草稿保留；旧账号配置不自动改写为新默认。
- 非 7860 端口和 IPv6 本机语音地址的状态、健康检查一致。
- 自定义 Agent 可以持有任务，未知 owner 不悄悄变成 main。
- zh/en/ja/ko/es 的回复模板和执行事件通过共享夹具；自然语言正文与工具输出不作为翻译 ID。
- 专项 → 按改动范围组合 → 构建/浏览器/Swift/Android；真实服务、真机和安装另计。

模型目录并非每家服务都返回能力元数据；缺失保持未知，用户可声明并做连接测试。提供方协议默认值与旧设备保存值仍保留，不能把未知说成“已支持”。iPhone 旧图片默认值也放入同一注册表，保留兼容值而不改用户的图片模型。

新增 Agent 回复语言与模型能力是各设备的本地配置。当前严格 v1 同步协议不增加未知字段；旧端同步时保留本机的语言选择，账号、密钥、模型连接仍不通过公开资料字段传播。新旧执行记录都可读。iPhone 的提供方托管搜索不开放服务商未提供的结果数/超时控制，不展示无效开关。

## 常量与配置登记

不把所有数字机械搬进一个跨模块全局文件。用户设置、运维调度和安全上限分别保留清晰入口：

| 用途 | 入口 / 默认值 | 处理 |
| --- | --- | --- |
| 搜索条数、请求时间 | `agentRuntime.search.maxResults` / `timeoutMs` | 设置页；1–8 条、3–120 秒，服务端再次校验。 |
| 搜索缓存 | `operationalLimits.search.cacheTtlMs` / `freshCacheTtlMs` | 默认 2 小时 / 15 分钟，可设 0；有界校验。 |
| URL 缓存、陈旧结果窗口 | `urlCacheTtlMs` / `staleMaxMs` | 默认 2 小时 / 24 小时，不改变新鲜度证据含义。 |
| 抓取预算与正文 | `contentTimeoutMs` / `contentMaxChars` / `fetchTimeoutMs` / `fetchMaxChars` / `browserTimeoutMs` | 默认 14 秒/6000 字、30 秒/20000 字、20 秒，集中在 `searchLimits.js`。 |
| 本机服务 | `customVoiceBaseUrl`、`localServices.ollama/lmstudio/llamacpp` | 本机 URL 严格解析；后者用于离线压缩候选，模型主连接依旧读用户选择。 |
| 归档频道判定 | `operationalLimits.remote.replyThreshold` / `grayMin` | 默认 .55/.30，范围 0–1 且灰区下界不超过阈值；渠道归档期间不增可交互入口。 |
| dreaming / 空闲调度 | `src/memory/dreaming/scheduler.js` 的调用参数 | 原本已有注入参数，不是无入口常量；本轮不重复记忆调度架构改造。 |
| 原生转写/定位端口 | Mac 壳计算配对端口，将实际桥地址注入 Node | `port+1` 是同一实例的绑定协议，Node 不拿 43128 猜当前端点；本轮保留配对避免破坏端口回退。 |
| 文件审批/权限到期、技能/解析上限、搜索竞争分支阈值 | 各领域契约与模块边界 | 保留安全/实现上限，不当作可任意关闭的设置。执行图坐标/颜色仍是设计值。 |

配置片段示例（合并进已有配置，不能替换整个配置文件）：

```json
{
  "customVoiceBaseUrl": "http://127.0.0.1:8923/v1",
  "agentRuntime": {"search": {"maxResults": 4, "timeoutMs": 25000}},
  "operationalLimits": {
    "search": {"cacheTtlMs": 7200000, "freshCacheTtlMs": 900000, "contentMaxChars": 6000},
    "remote": {"replyThreshold": 0.55, "grayMin": 0.30}
  }
}
```
