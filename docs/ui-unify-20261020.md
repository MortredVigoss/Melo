# 桌面 UI 全局审计与统一 · 2026-10-20

用户反馈：桌面版（尤其“系统”）框与字贴在一起、显示不全、文字框随意堆叠、设计语言不统一、右侧工作面不透明度不对、残留旧绿色。iPhone 版不动。

## 方法

隔离 MELO_HOME 起测试服务，自动遍历五个模块全部分支及系统设置五个分类，1440×900 与 1100×760 各截图；同时用几何探针统计“有边框/底色的相邻块间距 < 6px”“子卡片溢出父卡片”“浏览器默认样式的输入框/下拉框”和字号分布，并扫描全部 CSS/JS 中的绿/青/蓝色值。证据：`.tmp/ui-audit-20261020/`（before/after/narrow 截图、`probe-*.json`、`scan-colors.mjs`）。

## 发现 → 处理

| # | 问题 | 根因 | 处理 |
| --- | --- | --- | --- |
| 1 | 系统·工具与任务、安全、模型、技能、聊天文件共 7 处块与块贴边；任务/审批卡内文字贴卡片边 | `.detail-card` 为普通块流无间距；无修饰的 `.surface-card` 没有内边距 | detail-card 统一 16px 网格间距；纯 surface-card 补 16px 内距 |
| 2 | 说明文字比标题大、各页字号乱（工具与任务 49 处 16px） | 未设字号的文字继承浏览器 16px | 工作面基准 13px；h2 17 / h3 15 / 说明 13；用 `:where()` 零优先级，显式字号（聊天字号设置、输入区、页标题）不受影响 |
| 3 | 灰色方框输入框、透明无箭头下拉框（安全筛选、记忆搜索、计价、Agent 切换） | 浏览器默认控件；`.config-select` 透明无边框 | 统一 inset 输入井与金色箭头；只读（disabled）值保持安静文字 |
| 4 | 右侧工作面透出星空，叠层卡片明暗不一 | 工作面材质 alpha 0.54–0.65，嵌套卡片叠加 | 工作面提到 0.95–0.97；嵌套卡片改为轻 inset 无阴影 |
| 5 | 系统设置页卡片 20px、偏冷青渐变、居中 880px、额外 eyebrow | 独立样式未接入共享骨架 | 与其他管理页同左边缘、26px 标题、16px 共享卡片 |
| 6 | 模型页摘要卡 860px 居中、表单 760px 截断使“编辑”按钮悬在中间 | 历史 max-width | 统一满宽 |
| 7 | 连接器/技能列表列 160px：搜索框、标签、导入按钮被截断 | 网格列过窄 | 列宽 220–250px，窄窗口（工作面 ≤760px）改单列 |
| 8 | 旧绿/青/蓝残留 | 旧 emerald/冷色主题 | 保存成功提示、设置通知、能力状态卡、执行完成状态、diff 新增边框、引用标记与抽屉高亮全部改为黑金语义色 |

修后探针：除聊天输入区（无边框输入框，设计如此）与原子按钮 1px 装饰外，全部页面贴边 / 溢出 / 未样式控件为 0。

## 实现边界

- 新增 `desktop-ui/surfaceUnify.css` 最后载入；只改表现，不改任何 handler、状态、标记或保存路径。
- 新 token 只放在 surfaceUnify.css，不改 `neuralGlass.css` 的 `:root`，因此 `ios/scripts/sync-theme.py` 生成的手机主题不变。
- “知识”模块的暗青灰身份色（`#506e77 / #91b3bb`）是 2026-10-08 记录的五区分色决定，同时驱动 GPU 场景与手机，本轮未改，待用户决定。
- 未处理：连接器 / 技能 / 安全页的英文文案（i18n，U6）；聊天气泡中列表后紧接段落无间距（回复渲染）。
