# 界面语言系统（2026-10-15）

用户要求中文、英文、韩语、日语等四五种语言，在系统设置和左下角切换。本轮采用中、英、韩、日、西班牙语，默认延续中文。

方案：显式 UI 词条与本机偏好（9/10，能保护用户内容、可测试与扩展）；整页 DOM 自动翻译（3/10，会误改消息/资料并影响流式刷新，弃用）。依照本次实现授权直接执行。

界面语言不改变模型请求语言，不翻译历史消息、用户名称、输入草稿、文件和服务原始错误。设置仍只读起步，编辑保存后生效；快捷入口直接表达切换意图。偏好属于设备，不纳入工作区同步。
