# iPhone 前台朗读专项 · 2026-10-12

用户反馈前台自动朗读开关开启后无声。当前源码有保存和完成触发，缺少独立的播放音频会话；语音输入留下 record 类别，朗读沿用应用音频会话。桌面开关与 iPhone 开关各自保存。

计划：让系统管理独立朗读音频会话，避免录音配置影响播放；前台退出立即停止；增加试听与真实开始/结束/失败状态；用隔离模拟器验证 record 模式之后的朗读，以及开关关闭和后台不播。保留聊天、账号与现有设计。

真机调试连接第一次失败，安装版本与实机可听性尚未核实。本轮不擅自覆盖正在使用的手机。

## 验证结果

- 真机只读确认：0.5.15（20），`melo.autoSpeak` 与 `melo.voiceLanguage` 均未保存，自动朗读按默认关闭处理。读取临时偏好文件后已清理，仅保留这两个字段的检查结果。
- iOS Debug 模拟器构建通过。`-melo-verify-speech-playback` 隔离 fixture 验证开关关闭、后台不播、record 模式之后系统确认开始朗读、离开前台停止、试听无需打开自动朗读及停止操作。
- 独立会话使用 Apple 提供的 `AVSpeechSynthesizer.usesApplicationAudioSession = false`；系统管理播放、混音与生命周期，不改写录音所用会话。
- 未修改手机设置、未覆盖安装或重启真机；模拟器收到真实朗读开始回调，不等同于已验证真机扬声器可听、静音开关或蓝牙设备。
- 用户操作：手机系统设置 → 语音 → 编辑 / 修改 → 开启“在前台自动朗读回复” → 保存。只对随后完成的新回复生效，桌面开关不会同步覆盖手机。
- 构建日志及 fixture 结果：`.tmp/ios-speech-20261012/`。源码快照不含聊天与密钥。播放试听和失败状态需使用本次修复后的新包。
