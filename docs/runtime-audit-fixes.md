# 2026-10-10 运行链路审计修复

用户在逐项核实 Claude 报告后授权按顺序修复。方案评级 A：范围集中于执行正确性、非破坏性保留与队列占用；主要风险是重复外部副作用及历史回看退化，必须用隔离目录和真实 HTTP 契约验证。当前共享工作树有大量其他线程的未提交内容，按改前基线保存本轮差异，不混入无关提交。

1. 操作账本：同一次调用重传复用收据；不同调用重新执行。简单只读探测不缓存。明确未启动的操作释放记录，已知退出码保留结果；超时、已开始后取消及其他结果不明的操作继续要求核对。构建脚本仍经过原有权限闸门，不假定它没有副作用。
2. 对话保留：十条仅为最近列表限制。加载、创建、同步均不隐式删历史。删除对话后在状态锁外取消关联提醒，避免锁顺序倒置。
3. 提醒：永久错误停止；临时失败指数退避，最多五次后暂停。状态和原因可通过原提醒列表查看并取消/重新设置。外部发送前持久化发送意图；断电或网络异常后无法证明送达的状态保留待核对，不能承诺外部服务 exactly-once。发送成功、清理保存失败仅重试保存。
4. 启动：进程启动做一次恢复，窗口 launch/reset 只负责界面选择状态。
5. 执行历史：主状态每聊天保留最近 50 条终态及全部进行中记录，已提交的旧终态先落 SQLite 归档再从主清单移除。归档参与请求去重，场景文件保留。任务空间每页 20 条、支持更早记录和指定 runId 回看；网页节点的 5/10 上限完全不变。旧回答滚入视口时按需恢复场景及图片选择。
6. 后台命令：审批前断开仍取消；获批启动的 HTTP 后台命令由服务拥有，查看连接断开仅解绑输出。完成记录最多 20 条，30 分钟过期，运行中的进程不因清理被移除；显式停止、超时、服务关闭仍终止进程。
7. 工具上下文：在 beginChatRun 时绑定角色、项目及精确运行的任务 ID；正常工具调用不再为定位任务排队读取完整状态。工作目录的真实路径/设备/inode 仍逐次核验。无聊天绑定的其他入口保留一次状态读取兜底。
8. 手机同步：场景读取移至锁外，最多四个并行 I/O；合并前核对消息内容及同步版本，过期读取不能清空或覆盖最新场景。
9. 新建对话：创建成功后清空未发送附件；失败保留草稿及附件。

不实施未证实的报告项：运行中重复 requestId 已由每聊天调度队列处理；缺失日期已有标准化；旧语音字段当前没有有效写入源。本轮不改供应商登录/模型/图像能力，不动现有账号凭证。
