# 实时语音对话优化建议 · 2026-11-18

审计基于本机 master 的 a3f49ce6，覆盖 Mac 桌面和 iPhone 的通话入口、声音引擎、回复事件、分句和播放。建议沿用已经选定的级联方案。首要目标是每句话只在所属通话播放，用户开口时能可靠接管，核验完成后尽快听到第一句有效回答。

普通文字聊天在桌面有增量显示，iPhone 的 ChatStore 有临时回复草稿。语音把答案送入扬声器有自己的交付边界。需核验的事实、工具结果和操作完成声明，应当只读已经获准交付的内容。若希望提前播报，可先试“在核验期间仅为候选首句准备音频”，仅在最终首句、口播规则、Agent 音色和轮次全部匹配时播放。额外合成费用、丢弃率与第三方音色的草稿披露须单独评估，首期优先本机音色。

## 落地与验收

1. 先修旧会话迟到事件和回声误判。增加快速重拨、换聊天、同聊天重拨、重开后迟到审批、连续打断以及半双工测试。验收要求旧会话向新播放器提交 0 句，迟到结束事件更改新通话状态 0 次。
2. 在两个宿主记录单调时间戳。分别标出用户话音结束、转写提交、首个屏幕文字、最终回答获准、首段音频交给播放器、首个可听回答。审批或“我查一下”独立计时。软件播放事件早于扬声器实际出声，做一次声学对照校准。仅记录时长和原因码即可。
3. 桌面系统音色复用共享分句规则，服务端音色按播放进度补充队列。在相同模型、音色、网络与测试语句下，分别覆盖 Mac / iPhone、扬声器 / 蓝牙、短问答 / 搜索任务。每组至少 20 轮，报中位数和 P95。初始工程目标是定稿到首句可听的中位数减少 25%，有效插话到静音的 P95 小于 400 ms，且误断句率、漏停率和回声误触率均不升高。首轮采样后校准目标。
4. 只有当首句仍主要耗在等待核验，且本机音频准备占足够比例时，再评估候选首句预合成。耗时若主要在模型或工具，应回到对应阶段优化。首句和整轮完成时间分开报告。

## 11 月 18 日实施边界

桌面从聊天流 handleSendMessage 的 observer 到 createVoiceCall 的计划、合成和原生桥，由 VoiceCall 驱动 SystemVoiceCallAudio 播放。iPhone 从 ChatStore 的草稿、落盘消息和发送状态到 VoiceCallController，再进入同一引擎。审计范围含首次建聊天、重拨、补充、进度提示、审批、取消、解码失败和半双工。变更只持有通话内存状态，已有文字交付、账号、聊天存储、模型核验和权限判定沿用原路径。音频系统回报首缓冲的位置作为软件测量终点，实体扬声器与蓝牙的实际声音需另行采样。自适应断句和未定稿首句预合成仍由上面的实测条件决定。

### 已实现与实测

- 桌面观察器与第一次建聊天的回调都校验通话、轮次及页面归属。取消、挂断、同聊天重拨和旧请求的错误或审批均有回归。iPhone 的 ChatStore 在新请求开始、回答成功保存与请求结束处发送带 attempt ID 的内存事件。新通话只认自己观察到的请求，上一通的回答仍保存到原聊天。语音不读取流式草稿。
- 桌面系统音色本地分句。服务器最多合成当前句和下一句，当前句播放结束后才交下一句；解码降级用系统音色在原顺序重读，挂断或插话取消在途工作。最终回答就绪时，过期的进度口播让出播放器。iPhone 的原生播放器最多接收两个片段。
- 共享 Swift 引擎校验实际开始播放的片段和短暂尾音。排队但尚未播放的句子不参与回声匹配。最终识别出独立停止词时可打断；播放内容本身含该字时仍抑制回声。设备改变后两端更新半双工提示。音频图启用回声消除后若在 start 失败，两端尝试一次普通输入图；实际故障声卡仍需复验。
- 两端通过系统日志 com.melo.voice / turn-timing 记录轮次序号、阶段和单调毫秒数。识别端有对应的语音停止事件时记录到提交的间隔；另记首个可渲染文字、最终回答、首句送播放器、首次安排音频缓冲和插话至停止播放请求。提示语不计入首句。物理出声和扬声器静音仍需设备声学测量。
- 在本机用同一句中文和真实 speech-plan HTTP 处理器，对基准 3c7a8aed 与改后控制器交错测量，各 40 次。系统音色从有效最终回复到首次原生播放指令，中位数 0.767 → 0.016 ms，P95 为 2.570 → 0.056 ms，HTTP 计划请求 40 → 0。另用 Mac 系统中文音色静默渲染 PCM，首次 2154 ms，后续 20 次中位数 62.5 ms、P95 为 377.3 ms。后者是一组独立测量，不能相加推导真实对话延迟。
- iOS 26.4 临时模拟器实际运行 ChatStore、语音控制器及持久化，模型和音频设备用可控夹具。第一轮在重拨后完成，第一轮答案在原聊天完整保存，新播放器收到零句；接下来一轮保存并读出一次。回执在 `.tmp/voice-playback-20261118/simulator-final.json`。同目录含初始失败样例、本机前后对照和原生渲染证据。模拟器已清理。
- 尚待采样的是实体 Mac / iPhone 扬声器与蓝牙的端到端出声、漏停和误切率，以及真实工具任务。不凭本机小于 1 ms 的节省推断体感改善。自适应断句和候选首句预合成的启用条件尚未满足。
